# LC-3
The Little Computer 3 (LC-3) is a simple architecture I was tasked to implement during my CS 2110 class, where a base template was given and I was asked to implement most of the components. Certain parts like the 3 sign extension modes were given while components like the ALU, microcontroller, registers, and other components was within my task to build.

# LC-4200
The Little Computer 4200 (LC-4200) is an imaginary computer that is heavily based off of the LC-2200. This is a more pipelined architecture, supporting techniques such as stack framing, and is slightly more complex than the LC-3. In this project, we were tasked to fully construct the LC-4200, with no base template, so everything within the image is a product of my work.
