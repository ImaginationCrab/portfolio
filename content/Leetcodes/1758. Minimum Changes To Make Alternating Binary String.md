```
class Solution:
    def minOperations(self, s: str) -> int:
        n = len(s)
        a = int((1<<n+1)//3)
        x = int(s,2)^a
        m = x.bit_count()
        return min(m,n-m)
```

#Logic

* We can mathematically find the one of the alternating sequences, in our case it starts with a 1
* We use the XOR operation (which finds all differentiating bits)
* On the remaining bit sequence, we just count the # of bits
* To consider the other sequence, we just use n-m, as this is the number of flips needed to find the other sequence
* Return the minimum of these two counts

#Complexity 

This implementation is very fast, almost exclusively using bit operations. Since len() is $O(1)$ we only need to consider the bit shifting, the bit counting, the division, and the XOR, which all depend on machine word size. But they are all effectively $O(1)$, the bottleneck actually comes from the int() operation, where it is $O(n)$, so my implementation is $O(n)$.
