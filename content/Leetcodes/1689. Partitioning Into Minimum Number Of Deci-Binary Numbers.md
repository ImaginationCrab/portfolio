class Solution {
    public int minPartitions(String n) {
        int max = -1;
        for(int i = 0;i<n.length();i++){
            if((int)(n.charAt(i)-'0')>max){
                max = (int)(n.charAt(i)-'0');
                if(max==9){
                    return max;
                }
            }
        }
        return max;
    }
}

#Logic

* The (almost) naive solution is sufficient for this problem
* Go through the string and look for the maximum digit
* Return the maximum digit

#Complexity

Due to the one 'for' loop, the solution is $O(n)$, optimized to cut off early and return when we find a digit of 9, which is the maximum required deci-binary numbers to make all numbers.
