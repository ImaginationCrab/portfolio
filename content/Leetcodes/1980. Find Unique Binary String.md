```
class Solution:
    def findDifferentBinaryString(self, nums: List[str]) -> str:
        arr_len = len(nums)
        n = len(nums[0])
        s = ""
        for i in range(n):
            if nums[i][i] == "1":
                s += "0"
            else:
                s += "1"
        return s
```

#Logic

* Flipping the $i^{th}$ bit of the $i^{th}$ string and adding it to our string will give a completely unique string from the rest

#Complexity 
The complexity is $O(n)$ as there is only 1 loop, and all other functions are $O(1)$. I wanted to see if I could apply numpy to this, however this solution is just the simplest and the most efficient.
