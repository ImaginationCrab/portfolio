```
import numpy as np

class Solution:
	def hasAllCodes(self, s: str, k: int) -> bool:
		arr = np.zeros(2**k, dtype=int)

		for i in range(len(s)-k+1):

			integer_value = int(s[i:i+k], 2)

			arr[integer_value] = 1

		if(arr == 0).any():

			return False

		return True
```

#Logic

* Create a table of all required values which is 2^k
* Then check the string array sliding window style, ticking values in the array we have found
* Due to how binary works, we can intuitively just use the integer found as the index for the array
* Then we check the array for any indices we haven't ticked, and return based on if a 0 was found

#Complexity

We find that the solution utilizes numpy for 2 calculations, and goes through the range of the string once. Now the complexity actually changes based on the values given to s:str or k: int, we find that if s:str dominates the complexity it is O(n), and if k dominates the complexity, it is $O(2^k)$
, which means the function is exponential worst-case.
