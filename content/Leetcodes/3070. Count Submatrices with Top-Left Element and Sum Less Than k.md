import numpy as np
class Solution:
    def countSubmatrices(self, grid: List[List[int]], k: int) -> int:
        arr = np.array(grid)
        row = len(grid)
        col = len(grid[0])
        dp = np.zeros((row+1,col+1))
        sum = 0
        for i in range(1,row+1):
            for j in range(1,col+1):
                dp[i][j] = dp[i-1][j]+dp[i][j-1]+arr[i-1][j-1]-dp[i-1][j-1]
                if dp[i][j] <= k:
                    sum += 1
                else:
                    continue
        print(dp)
        return sum

#Logic

* Very naive logic: use a dynamic programming table to store the size of the matrices found
* If it is larger than k, then end the column-wise loop and continue to the next row
* If it is smaller than k, increment the count
* The dynamic programming recurrence is the left cell + top cell - topleft cell + value in the original array
* The recurrence works this way as we use the principle of inclusion exclusion, to avoid overcounting certain cells
* Side-note: I had to make the dynamic programming table size row+1 and col+1 just to avoid out of bounds issues, since I need previous values that may not exist yet


#Complexity 
The complexity is $O(n^2)$, as there is a dominating loop that runs through the entire dynamic programming table. While this solution isn't the most efficient, it is very intuitive and presents many concepts that can be applied to other problems.
