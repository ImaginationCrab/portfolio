import numpy as np
class Solution:
    def largestSubmatrix(self, matrix: List[List[int]]) -> int:
        arr = np.array(matrix)
        col = len(arr[0])
        row = len(arr)
        dupe = np.zeros((row,col))
        for j in range(col):
            temp = 0
            for i in range(row):
                if arr[i][j] == 1:
                    temp +=1
                    dupe[i][j] = temp
                else:
                    temp = 0
        max = 0
        dupe = np.sort(dupe,axis=1)
        dupe = dupe[:, ::-1]
        print(dupe)
        for i in range(row):
            for j in range(col):
                if dupe[i][j] * (j+1) > max:
                    max = dupe[i][j] * (j+1)
        return int(max)

#Logic

* This is like the absolute brute force of the solution
* We create a 2D array to store consecutive 1's
* We sort the rows by descending order
* Then we run through the entire array again to find the max submatrix

#Complexity

This solution is incredibly slow, almost a fully naive solution. 2 runs through the entire array dominate the complexity, so $O(n^2)$. I am sure there is a better solution, but I solved this in like 30 minutes, and I have other work to do.
