```
class Solution:

	def sumRootToLeaf(self, root: Optional[TreeNode]) -> int:
		def dfs(node: Optional[TreeNode],s: str) -> int:
			if(node==None):
				return -1
			i = 0
			x = dfs(node.left,s+str(node.val))
			y = dfs(node.right,s+str(node.val))			
			if x == -1 and y == -1:
				return int(s+str(node.val),2)
			if x >= 0:
				i+=x
			if y>= 0:
				i+=y
		return i
	return dfs(root,"")
```

#Logic
* The idea is to produce a string in binary and then convert it to an int when a leaf is found
* Since only 0,1s are in the tree, we can use -1 as a way to determine a None node, and if both left and right of a node is a None node, we determine it is a leaf, and count the binary string and return it up the stack


#Complexity

O(V) since it has to go through the entire tree, with V being all nodes.
